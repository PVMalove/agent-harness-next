# Остановка запускает RCA, агент продолжает автономно

**Статус: ACCEPTED (2026-11-08).** Эпик #1022. Опирается на ADR 0031 (каталог FMEA) и ADR 0012
(бюджет попыток). Идея цикла — autoresearch Андрея Карпаты: цикл не просит разрешения, неудачу
записывает в журнал и идёт дальше.

## Контекст системы

Когда агент упирается в ошибку, он вызывает человека, и автоматический прогон становится ручным.
Корневая причина не ищется, баги харнесса теряются или описываются симптомом. Правила
подтверждения (создание тикета, открытие PR, запрет auto-merge) при этом должны остаться.

## Действующий контракт

- **Остановка** — любой вызов человека из-за ошибки: блок хука, непредвиденный отказ, тупик без
  проанализированного пути. Обычные вопросы агента (неясное требование, выбор решения, плановые
  подтверждения) остановкой не считаются.
- Ошибка с `FMEA:`-строкой: агент применяет сценарий восстановления и повторяет в пределах
  существующего бюджета трёх попыток (ADR 0012). Ошибка без неё: remedy — подсказка, при неудаче
  остановка.
- На остановке агент не ждёт ответа. Он запускает фазу RCA скилла `diagnosing-bugs`, пишет
  RCA-черновик в gitignored-файл под `docs/tasks` и берёт следующий свободный тикет по запросу
  frontier эпика; свободных нет — останавливается и сообщает.
- RCA: до пяти шагов «почему», каждый с доказательством, остановка на управляемой причине.
  Вводящий в заблуждение remedy считается дефектом харнесса.
- Каждый RCA заканчивается предложенной записью FMEA со сценарием восстановления (ADR 0031): в
  следующий раз этот отказ уже не остановит. Если корень в харнессе, в черновике есть и баг-тикет с
  разделом RCA; если в окружении или неверном использовании, остаётся только запись FMEA.
- Тикет в трекере создаётся только после явного «да» разработчика; перед черновиком агент ищет
  открытые `type::bug` с той же корневой причиной.

## Рассмотренные варианты

- **Ждать человека** (как сейчас): прогон остаётся ручным.
- **Агент сам создаёт тикет в автономном прогоне:** нарушает правило «изменения трекера только по
  подтверждению».
- **RCA только после исчерпания бюджета попыток:** не ловит блок хука, где попыток не было.
- **RCA по классу ошибки («дефекты харнесса»):** ошибка использования тоже может быть тупиком, а
  вводящий в заблуждение remedy — сам дефект.

## Операционные последствия

- Журнал исходов — файлы в `docs/tasks`, в Git они не попадают. Таблицы SQL для журнала нет;
  при необходимости его перенос в хранилище runtime — отдельный эпик.
- Правила Zero Auto-Merge, подтверждения PR и записи в трекер не меняются.
