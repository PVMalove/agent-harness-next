# Сравнение макетов до и после unslop

Отдельные визуальные веб-варианты для #879. Исходники в `../console-mockups/` не изменены.
Страница сравнения читает их локально, строит вариант в изолированном iframe и добавляет
`web-polish.css`. Новый сервер приложения, зависимости и сборка не нужны.

Из корня issue-ветки:

```bash
python3 -m http.server 8879 --bind 127.0.0.1 --directory docs/design
```

Откройте `http://127.0.0.1:8879/console-web-unslop/`. Через `file://` чтение соседних файлов
может быть запрещено браузером. Сервер раздаёт только документацию дизайна, не каталог
состояния проекта. Остановка — Ctrl-C.

Выберите один из 12 экранов, «До», «После» или «Рядом» и ширину. При ширине больше окна
прокручивается область iframe. В варианте работают переходы меню и крошек, мобильное меню
и раскрытие существующих примеров состояний. Кнопки показывают пояснение: никаких команд,
записей или подтверждений от имени человека просмотрщик не выполняет. Поля и табличные данные
остаются демонстрационными. Это сравнение оформления, не интерактивная реализация всех сценариев.

Сохранены палитра, статусные символы, функции и порядок разделов; изменены ритм отступов,
плотность меню, фон панелей, регистр заголовков, перенос длинных значений и компоновка на узкой
ширине. Фиксированные narrow-копии заменены адаптивной компоновкой того же основного экрана;
остальные исходные примеры доступны в раскрытиях. Отчёт с приоритетами:
[console-web-ux-audit-879.md](../console-web-ux-audit-879.md).

Рекомендации G1–G8 по поведению не считаются реализованными этим визуальным проходом.
Особенно: исторический мастер «Открыть проект» и запрет выхода при обновлении не становятся
контрактами веба; варианты содержат соответствующие пояснения ADR 0028. Утверждение новых
веб-сценариев остаётся за #880/#881. TUI #720 не меняется.
