Что изменено и как проверять

Одна адаптивная страница вместо двух вариантов фиксированной ширины. Компактное меню, единый фон, ровные отступы, обычный регистр заголовков, читаемые статусы, видимый фокус. Исторические дополнительные состояния находятся под основным экраном в раскрывающихся блоках.

Меню и крошки переключают демонстрационные экраны. Действия открывают пояснение без запуска команды; недоступные действия остаются недоступными. Это варианты для согласования оформления, а не реализация веб-консоли и не замена макетов #880/#881.

При выбранной ширине шире окна прокручивается только область сравнения. Для исходника это сохраняет его фиксированную компоновку; в веб-варианте можно проверить перестройку на 390 px.

Направление: спокойный, точный, собранный пульт наблюдения. Акценты — выбранная сессия и действие, требующее внимания. Изображения, графики и декоративная анимация не добавлены.
