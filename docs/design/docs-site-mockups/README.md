# Макеты публичного сайта Agent Harness Next

**Статус:** DRAFT, на ревью.
**RFC:** [docs/rfc/docs-site.md](../../rfc/docs-site.md).
**Основа:** дизайн-токены и паттерны веб-консоли, перенесённые в `site.css`.

## Экраны

| Файл | Экран | Что показывает |
| --- | --- | --- |
| `index.html` | Лендинг | Hero, install, статус beta, возможности, архитектура, demo, входы в docs |
| `docs.html` | Документация | Sidebar, статья «Быстрый старт», TOC, code blocks, callouts, pager |
| `architecture.html` | Архитектура | Ownership, Rust runtime, store, IPC, supervisor, безопасность, ADR |
| `demo.html` | Демо | Веб-консоль в iframe, переключатель ключевых экранов, пояснения |
| `console.html` | Консоль | Самостоятельная демонстрация: Главная, Доска задач, Оркестрация, Отчёты |
| `404.html` | Ошибка | Маскот H›, объяснение и возврат на главную |

Общие файлы: `site.css` (токены, layout, компоненты, responsive), `site.js` (тема, поиск,
copy, mobile sidebar, TOC, demo screens), `mascot.svg` (воксельный маскот). Внешних шрифтов, CDN и сетевых вызовов нет.

## Как открыть

```bash
cd docs/design/docs-site-mockups
python3 -m http.server 8765
# http://127.0.0.1:8765/index.html
```

Или откройте `index.html` напрямую в браузере; demo-iframe ссылается на
`console.html`.

## Решения

- **Тёмная тема по умолчанию**, светлая — переключателем; выбор хранится в `localStorage`.
- **Токены консоли:** фон `#161a20`, surface `#1b1f26`, primary `#6fa8dc`, accent `#d97757`,
  ok/warn/err из `execution-console.css`.
- **Типографика:** системный sans для чтения, mono для команд, версий, меток и кода.
- **Landing и docs — разные режимы:** лендинг продаёт и показывает, docs-страницы дают
  плотную навигацию, TOC и copy.
- **Sidebar** на мобильной ширине превращается в drawer; на десктопе TOC скрывается ниже 1100px.
- **Поиск** — демонстрационный: локальный индекс, `⌘K`/`/`, стрелки и Enter.
- **Demo** не запускает команды и не читает проект; это существующий интерактивный макет
  консоли, встроенный в страницу.

## Что здесь мок, а что настоящее

Настоящее: HTML/CSS/JS, ссылки между страницами, тема, copy, поиск, iframe с консолью.

Мок: данные, команды, версия `beta`, статус и тексты установки. Перед публикацией контент
проходит проверку по `integration/harness-runtime-reliability` и релизный gate.

## Ограничения

- Целевой URL `https://pvmalove.github.io/agent-harness-next/` требует переименования
  репозитория; сейчас GitHub Pages для `claude-agent-harness` даст другой путь.
- Макеты не являются финальной вёрсткой MkDocs Material: это дизайн-контракт для темы,
  навигации и компонентов.
- В `docs.html` разделы «Hooks», «Verification» и «Release Gate» — демонстрационные якоря;
  полные страницы появятся в тикетах миграции.
