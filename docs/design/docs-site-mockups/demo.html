Веб-консоль

Полная браузерная альтернатива терминальному пульту: задачи, оркестрация, отчёты, восстановление, публикация и живые шаги агентов. TUI и браузер — клиенты одного Сервера консоли.

Что внутри

Один пульт для человека и агента

Консоль показывает факты, которые уже возвращает CLI, и добавляет живое наблюдение. Она не заменяет approval и не запускает команды без подтверждения.

▣

Задачи и оркестрация

Доска задач, batch, dispatch, QA lane и публикация — в одном месте, с фильтрами по роли и статусу.
