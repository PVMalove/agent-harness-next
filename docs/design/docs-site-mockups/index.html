Гарантии

  • 01Один writer. Python не пишет operational state в обход runtime.
  • 02Идемпотентность. Повтор после потерянного ответа возвращает тот же результат.
  • 03Audit. Хэш-цепочка и ledger validate --full обнаруживают удаление, вставку и перестановку.
  • 04Recovery. После SIGKILL runtime находит исполнение по меткам и доводит остановку до конца.
  • 05Границы. Worker не получает сокет движка или runtime; QA идёт в отдельном контейнере.
