# Доска задач: ручная приёмка #914

Основа: [шаг 14](README.md#доска-задач--шаг-14), маршрут `#board` прототипа.
Реализация: React-маршрут `#/board` из общего AppShell, общий `execution-console.css`, данные —
снимки сервера `task_board.specs` и `task_board.snapshot` (#913). Страница только читает:
перенос карточек, drag & drop и смена статуса относятся к #915.
Чек-лист предназначен для ручной приёмки владельцем; автоматические проверки её не заменяют.

- [ ] Заголовок «Доска задач», подзаголовок, факты: название и ветка спеки, число задач, время
      снимка; действия «Обновить» и «Оркестрация».
- [ ] Переключатель спек показывает «#n · название — N задач»; выбранная спека сохраняется в
      браузере и восстанавливается, пока трекер её перечисляет.
- [ ] Четыре KPI: «Открыто … из N задач», «С блокерами», «Активный batch», «Снимок»; при
      недоступном журнале «Активный batch» показывает «нет данных».
- [ ] Поиск, приоритет P0–P2, «Без блокеров» и «Сбросить» сужают карточки; «X из Y» считает
      видимые карточки, счётчик колонки — число её видимых карточек.
- [ ] Пять колонок: «Бэклог», «Готово к работе», «В работе», «Review / QA», «Готово» с
      подсказками макета; пустая колонка подписана «пусто».
- [ ] Карточка: номер, приоритет, заголовок, первая строка What to build, команда, чип
      «dispatch: роль», «блокеров: N» или «без блокеров», «критериев: N», ссылка «Открыть».
- [ ] Событие журнала по тикету или batch открытой доски перечитывает снимок с `force` без
      перезагрузки страницы; без событий доска перечитывается по TTL снимка (60 с).
- [ ] Модальное окно: «#n · спека», заголовок, метки, story points, issue, PR, ветка и текущий
      статус без элемента смены; вкладки «Контекст», «Acceptance (N)», «Промпт».
- [ ] «Копировать» копирует промпт, а на вкладке Acceptance — пронумерованные критерии; при
      отказе буфера обмена текст показан и выделен для ручного копирования.
- [ ] HTML, скрипты и Markdown из тикета показаны как текст; ссылка не http(s) не выводится.
- [ ] Состояния «Спек пока нет», «На доске нет задач», «Обновление доски» и баннер «Трекер
      недоступен» с причиной, сообщением и возрастом снимка соответствуют макету.
- [ ] ru/en переключается без перезагрузки; все подписи доски переведены.
- [ ] На 390 px колонки прокручиваются горизонтально внутри доски, страница не переполняется;
      модальное окно помещается в экран.
- [ ] Шрифты, цвета, интервалы и диалог сверены с макетом на 1440/390 px.

## Отличия от демонстрационного макета

Демо-значения макета (номера спек и тикетов, сообщение трекера, «2 мин», ссылки на репозиторий)
в консоль и фикстуры не попадают: фикстуры собираются из синтетических данных через
`TaskBoardService` (`tests/console/test_web_fixture_task_board.py`). Поле без источника в снимке
показывает «нет данных». Счётчик колонки считает карточки, видимые после фильтров, как в макете.
Селектор демо-состояния, баннер «Идёт мутирующая команда», перетаскивание, смена статуса и
диалог подтверждения переноса не переносятся (#915).

## Автоматические артефакты

`tests/web/task-board.spec.ts` проверяет колонки, счётчики, карточку, модальное окно, вкладки,
четыре состояния, отсутствие горизонтального переполнения и политику CSP на 1440 и 390 px по
структуре страницы, без сравнения скриншотов.
`tests/web/task-board.test.tsx` и `tests/web/task-board-modal.test.tsx` проверяют фильтры,
живое обновление, TTL, состояния, вывод текста и копирование.
`tests/web/test_task_board_network.py` проверяет настоящее приложение FastAPI поверх ASGI с
поддельным GitHub и подписи ru/en.
