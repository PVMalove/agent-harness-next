# Навигация Harness Console 2.0.0 · вариант A

**Статус:** согласована владельцем 4 ноября 2026. **Основание:** анализ
`integration/harness-runtime-reliability` и решение «сначала навигация, потом по одному экрану».

## Принципы

1. В меню — только стабильные места, а не динамические фильтры.
2. «Главная» — статистика Harness и короткая сводка последних задач, без полного реестра.
3. Роли и статусы — фильтры внутри «Хода работы» и «Оркестрации», а не пункты меню.
4. «Публикация», а не «GitHub»: проект может использовать GitHub, GitLab или локальный трекер.
5. Названия — продуктовые, без терминальной нумерации 0–9.
6. Меню сворачивается до иконок; состояние запоминается. Контекст на Главной — блок над задачами.
