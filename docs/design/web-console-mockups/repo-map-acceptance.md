# Repo Map: ручная приёмка #888

Основа: [шаг 10](README.md#repo-map--шаг-10), маршрут `#repo-map` прототипа.
Реализация: React-маршрут `#/repo-map` из общего AppShell, общий `execution-console.css`.
Чек-лист предназначен для ручной приёмки владельцем; автоматические снимки её не заменяют.

- [ ] Заголовок Repo Map, действия «Обновить», «Перестроить», «Экспорт», текущий HEAD.
- [ ] Четыре KPI показывают факты снимка: tier, файлы, связи, оценку токенов; неизвестное — `—`.
- [ ] Вкладки «Обзор», «Символы», «Связи» соответствуют макету; дополнительная вкладка
      «Настройки» показывает данные TUI о политике, парсерах, языках и памяти.
- [ ] В обзоре есть индекс и покрытие в двух колонках на десктопе, дерево файлов слева,
      сигнатуры и исходящие/входящие связи справа; выбор файла обновляет детали.
- [ ] Provenance парсера и диагностики доступны при прокрутке обзора. Значения взяты из снимка.
- [ ] Поиск символов фильтрует сигнатуры и пути; выбор строки показывает связи её файла.
- [ ] В «Связях» граф и таблица показывают файлы, тип и достоверность; граф ограничен первыми
      десятью файлами с явным счётчиком. Клик по узлу фильтрует символы этого файла.
- [ ] Хабы считают уникальные входящие файлы, как TUI; повторные связи разных типов не
      увеличивают входящую степень.
- [ ] Настройки показывают requested tier и причину недоступности редактирования, registry,
      пару, источник и грамматики парсера, языки проекта; память — состояние, причину,
      источники, число документов, top_k и max_tokens.
- [ ] «Перестроить» открывает предупреждение об offline parser bundle и показывает commit;
      отмена не запускает команду, подтверждение создаёт серверную job для этого commit.
- [ ] Идущая job показывает статус, id, код возврата и подтверждаемую отмену. «Занято», ошибка,
      обрезанный вывод и отсутствие HEAD не выдаются за успешное построение.
- [ ] После обрыва соединения job продолжается, клиент возобновляет чтение вывода без
      повторного запуска. Построенная карта показывается только для совпадающего HEAD.
- [ ] Экспорт скачивает исходную карту JSON; ru/en переключается без перезагрузки.
- [ ] На 390 px колонки складываются, меню работает через drawer; горизонтальная прокрутка
      ограничена графом/таблицей. Длинные пути и provenance остаются читаемыми.
- [ ] Шрифты, цвета, состояния выбора, интервалы и диалог сверены с макетом на 1440/390 px.

## Отличия данных от демонстрационного макета

Контракт TUI содержит пути, сигнатуры и связи файлов, но не содержимое файлов, номера строк,
описания символов, generation и распределение source/docs/tests/excluded. Эти данные не
имитируются: вместо содержимого показаны сигнатуры, вместо демонстрационных агрегатов —
наблюдаемое покрытие парсером. Граф показывает реальные файлы, а не придуманные модули.
Настройки в этой задаче показывают факты; изменение конфигурации остаётся в существующих
командах настройки. Построение, в отличие от демонстрационного макета, выполняется сервером.

## Автоматические артефакты

`tests/web/repo-map.spec.ts` проверяет состояния, вкладки, подтверждение и отсутствие
горизонтального переполнения при 1440 и 390 px. Скриншоты не сравниваются: соответствие макету
владелец проверяет вручную по этому чек-листу.

`tests/web/test_repo_map_network.py` проверяет настоящий FastAPI/WebSocket, cookie,
производственный процесс CLI, закреплённый commit, продолжение job после отключения клиента,
данные общего снимка и подписи ru/en. Fedora SELinux/rootless Podman и Windows этим
сценарием не проверяются.
