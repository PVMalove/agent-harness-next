# Фронтенд консоли

Здесь будут исходники SPA консоли на React и TypeScript, а в `dist/` — их сборка.
`harness.console.backend.api` отдаёт `dist/` по корню сервера, когда в нём есть
`dist/index.html`; без сборки сервер отвечает простой текстовой страницей.

React-кода и сборки в репозитории пока нет. Python-пакета в этом каталоге нет.
