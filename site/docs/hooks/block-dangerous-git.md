# block-dangerous-git

## 1. Название и локализация
- **Английское название:** block-dangerous-git.sh
- **Русский перевод / Суть:**

```text
Блокировка опасных Git-команд
```
## 2. Полное описание
Хук `PreToolUse(Bash)` не даёт агенту запустить Git-команды, которые теряют незакоммиченные изменения: `git reset --hard`, `git clean -f`, `git branch -D`, `git checkout .` и `git restore .`. Такую операцию выполняют только по явной просьбе пользователя. Скрипт взят из скилла "git-guardrails-claude-code", но `git push` он намеренно не блокирует: пуш в защищённые ветки запрещает отдельный хук `block-direct-master.sh`.

Хук разбирает команду как shell, а не ищет строку в сыром тексте. Он блокирует только запуск `git`: слово команды, в том числе внутри `$(...)`, обратных кавычек, `sh -c`/`bash -c`, `eval` и тела heredoc, которое подаётся в оболочку (`bash <<'EOF'`). Слова, которые на той же строке уходят в оболочку через `|`, `<<<` или `<(...)` (`echo "..." | sh`), хук тоже разбирает как скрипт. Та же строка в кавычках, в аргументе другого интерпретатора (`python -c "..."`) или в теле heredoc для не-оболочки (`python - <<'EOF'`) считается данными, и команда проходит. Если команду разобрать не удалось (например, кавычка не закрыта), хук ищет опасные шаблоны в сыром тексте и при совпадении блокирует.

Известные ограничения:

- Хук не видит команду, которую запускает другой интерпретатор или удалённая оболочка (`python -c "os.system(...)"`, `ssh host '...'`), и содержимое файла, переданного в оболочку (`cat x | sh`, `bash script.sh`).
- Глобальные опции `git` (`git -C dir reset --hard`) хук не разбирает, и такая команда проходит.
- Оболочкой хук считает любое слово `sh`/`bash`/`zsh`/`dash`/`ksh`/`eval` на строке. Поэтому редкая команда вроде `grep bash <<EOF` с опасной строкой в теле блокируется. Это ложное срабатывание в безопасную сторону.
## 3. Контракты
- **Вход (Input/Brief):** JSON вызова инструмента через stdin; команда лежит в поле `tool_input.command`.
- **Выход (Output/Report):** код `0`, если опасных шаблонов нет. Если команда заблокирована, код `2` и сообщение в `stderr` с найденным шаблоном. Через [конверт hook-response](hook-response.md) вердикт получает `reason_code` `dangerous-git`. Если Python 3.9+ не найден, хук блокирует любую команду кодом `2`.
