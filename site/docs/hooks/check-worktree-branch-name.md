# check-worktree-branch-name

## 1. Название и локализация
- **Английское название:** PreToolUse: Check Worktree Branch Name
- **Русский перевод / Суть:**

```text
Проверка имени ветки worktree перед её созданием: соглашение об именах проекта и наличие задачи в трекере.
```
## 2. Полное описание
Хук `check-worktree-branch-name.sh` срабатывает перед вызовом инструмента `EnterWorktree` (событие PreToolUse). Он проверяет имя ветки, которую создаёт `EnterWorktree`, по тем же правилам "Issue First" и `branch_pattern`, что и [check-branch-name](check-branch-name.md).

Как хук решает:
1. Хук читает JSON вызова из stdin и берёт из него поле `"name"` регулярным выражением.
2. Если имя не задано (например, агент входит в существующий worktree по пути), хук ничего не проверяет.
3. Если имя задано, хук сверяет его с регулярным выражением `branch_pattern` из `.harness/project.json` (по умолчанию `^feature/issue-[0-9]+-.+`). Если имя не подходит, хук блокирует вызов.
4. Если имя подходит, хук берёт из него номер issue: первую последовательность цифр.
5. Номер хук передаёт в `tracker-issue.py`, это та же проверка, что у `check-branch-name.sh`. Трекер и проект определяет резолвер трекера проекта (поле `tracker` или `origin`), а `gh`/`glab` получают явный `-R`. Проверку `tracker-issue.py` пропускает, если трекер локальный, путь проекта неизвестен, пакета `.harness/health` нет или CLI не установлен. Если Python нет, хук блокирует создание, как и `check-branch-name.sh`.
6. Если issue не найдена, issues в проекте отключены, CLI не авторизован или проект недоступен, хук прерывает вызов инструмента и называет причину.
## 3. Контракты
- **Вход (Input/Brief):** JSON с аргументами вызова `EnterWorktree` через `stdin`. Поле `"name"` необязательно.
- **Выход (Output/Report):** код `0`, если проверка прошла или имени нет. Код `2` и причина в `stderr`, если имя нарушает соглашение или issue не удалось подтвердить: issue не найдена, issues отключены, нет авторизации, проект недоступен, CLI не ответил за 10 с или завершился с нераспознанной ошибкой.
