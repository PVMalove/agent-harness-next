# count-skill-usage

## 1. Название и локализация
- **Английское название:** count-skill-usage
- **Русский перевод / Суть:**

```text
Сбор статистики вызовов скиллов.
```
## 2. Полное описание
Хук `PreToolUse(Skill)` считает, сколько раз агент вызвал каждый скилл, чтобы потом это проанализировать. Хук работает по принципу best-effort и никогда не блокирует агента: скрипт всегда завершается кодом `0`. В [конверте hook-response](hook-response.md) он учётный: если его код ненулевой, конверт считает это внутренней ошибкой и разрешает вызов с предупреждением.

Как хук считает:
1. Читает JSON из `stdin` и берёт из него имя скилла (поле `"skill"`) через `grep` и `sed`.
2. Если имя есть, хук ищет файл `.claude/.skill-usage.json` в каталоге `CLAUDE_PROJECT_DIR` (по умолчанию в текущем каталоге). Если файла нет, хук создаёт его с пустым JSON-объектом `{}`.
3. Читает из файла текущее число вызовов этого скилла.
4. Увеличивает счётчик на 1.
5. Обновляет файл через `sed`: для нового скилла добавляет пару «ключ-значение», для известного меняет значение счётчика.
## 3. Контракты
- **Вход (Input/Brief):** JSON из `stdin` с полем `"skill"`, в котором стоит имя вызванного скилла. Необязательная переменная окружения `CLAUDE_PROJECT_DIR`.
- **Выход (Output/Report):** всегда код `0`. Хук создаёт или обновляет файл `.claude/.skill-usage.json` со статистикой по скиллам.
