# require-bounded-check.sh: ограниченный вывод проверок

## 1. Название и локализация

- **Исходный хук:** [`harness/project/hooks/require-bounded-check.sh`](https://github.com/PVMalove/agent-harness-next/blob/master/harness/project/hooks/require-bounded-check.sh)
- **Русский перевод:** требование ограниченного вывода полного тестового прогона.

## 2. Полное описание

Хук `PreToolUse(Bash)` не даёт запустить полный тестовый прогон без обёртки
`qa-gate/scripts/test_summary.py`. Обёртка сокращает и очищает вывод, прежде чем он попадёт в
историю сессии. Хук читает команду из входного JSON. Если в проекте нет `.harness/project.json`,
хук ничего не блокирует. Если конфиг есть, хук проверяет команды из `qa_gate_commands`, полный
`pytest` и полный `python -m unittest`. Команда, в тексте которой есть `test_summary.py`, проходит.
Точечный `pytest` с node ID `::` и `unittest` с полным dotted-путём теста тоже проходят без обёртки.

Упоминание имени хук запуском не считает. Общий shell-парсер `pr_commands.py` сохраняет границы
аргументов и разбирает простые команды, вложенные оболочки и исполняемые подстановки. Поэтому хук
пропускает текст DoD в `gh issue create --body`, описание `glab issue create`, сообщение
`git commit`, аргументы `echo`/`printf` и команд чтения, комментарии и буквальный текст heredoc.
Настоящий запуск через `bash -c`, `eval`, `timeout`, `find -exec`, `$(...)`, обратные кавычки,
process substitution или heredoc оболочки хук блокирует. Исполняемый текст, который парсер не
разобрал, и код интерпретатора хук проверяет консервативно, по подстроке.

Хук поведенческий: в профиле `minimal` [конверт hook-response](hook-response.md) понижает его
блокировку до предупреждения.

## 3. Контракт

- **Вход:** команда Bash в stdin и `.harness/project.json` целевого проекта. Для разбора нужны
  Python 3.10+ и соседний `pr_commands.py`. Если конфиг есть, а Python или модуль дали ошибку, хук
  возвращает код `2`.
- **Выход:** код `0` для разрешённого вызова. Для полного прогона без обёртки код `2` и команда
  исправления в stderr.
