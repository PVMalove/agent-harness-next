# Database Migrations: миграции базы данных

## 1. Название и локализация

- **English:** Database Migrations
- **Русский (1:1):**

```text
Миграции базы данных
```

## 2. Полное описание

Database Migrations: write-роль для границ схемы и данных. У координатора пока нет маршрута dispatch для этой роли (#1159): её не планируют, а тикет, которому нужна миграция схемы или данных, эскалируется координатору.

Предполагаемая область роли: allowed paths brief для базы данных или инфраструктуры, без несвязанных изменений сервиса. Результатом была бы миграция с условиями rollout и rollback, подтверждённая проверками миграции и совместимости проекта.

## 3. Контракты

- **Вход (Input/Brief):** неизменяемый brief с изменением схемы или данных, разрешёнными путями, стратегией совместимости, DoD, запретами и проверками миграции.
- **Выход (Output/Report):** commit SHA миграции; changed files; результаты проверок миграции и совместимости; условия rollout и rollback, риски, блокеры и следующий gate.
