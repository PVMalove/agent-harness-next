# Grill With Docs: прожарь с документами

## 1. Название и локализация

- **Английское название:** `grill-with-docs`
- **Русский перевод:**

```text
Прожарь с документами
```

## 2. Полный перевод текста скила

<div class="ah-skill-text" markdown="1">

```yaml
name: grill-with-docs
description: Неумолимое интервью, которое оттачивает план или дизайн и попутно создаёт документацию (ADR и глоссарий).
disable-model-invocation: true
```

Запустите сессию `/grilling` со скиллом `/domain-modeling`.

</div>

## 3. Контракты

- **Вход (Input/Brief):** идея, план или решение в рабочем каталоге.
- **Выход (Output/Report):** уточнённый план и при необходимости обновлённые ADR и глоссарий.
