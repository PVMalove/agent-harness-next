# Grill With Docs: прожарь с документами

## 1. Название и локализация

- **Английское название:** `grill-with-docs`
- **Русский перевод:**

```text
Прожарь с документами
```

## 2. Полный перевод текста скила

<div class="ah-skill-text" markdown="1">

```yaml
name: grill-with-docs
description: Проверяет идею или план вместе с /domain-modeling. Записывает согласованные термины в CONTEXT.md и предлагает ADR для значимых решений. Для интервью и Discovery Context используйте /grill-me.
disable-model-invocation: true
```

Запустите `/grilling` с `/domain-modeling`. Перед правкой глоссария или ADR прочитайте
`references/domain-doc-writes.md` навыка `/grilling` и следуйте ему. Эти правила главнее правила
`/domain-modeling` о немедленной записи:

- По `CONTEXT-MAP.md` определите нужный контекст. Согласуйте с пользователем термин, определение и контекст. Если глоссария ещё нет, создайте его для первого согласованного термина, когда каталог доступен для записи.
- Перед правкой проверьте права и статус Git. Если файл доступен только для чтения или содержит незакоммиченные изменения вне сессии, сохраните согласованный термин в чате.
- Предложите ADR, если решение трудно отменить, его причины неочевидны и был выбор между реальными альтернативами. Создайте ADR после отдельного согласия пользователя: в `docs/adr/` владеющего контекста или в корневом `docs/adr/`, если решение затрагивает несколько контекстов.
- В итоговом сообщении назовите изменённые термины и файлы, предложенные и созданные ADR и термины, которые не удалось записать.

</div>

## 3. Контракты

- **Вход (Input/Brief):** идея, план или решение в рабочем каталоге.
- **Выход (Output/Report):** уточнённый план и при необходимости обновлённые ADR и глоссарий.
