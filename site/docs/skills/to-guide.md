# /to-guide — руководство для ручной реализации

Запускайте `/to-guide` вручную (в Codex используйте `$to-guide`) для `hitl`-тикета, который человек
реализует сам. Навык готовит пошаговое руководство с готовыми промптами для AI IDE (Cursor, Copilot
Chat). Код, ревью, `qa-gate` и PR остаются за человеком, а руководство называет точные команды для них.

## Подготовка

1. Навык читает тикет и проверяет блокеры. Если тикет в `status::specs` или без `hitl`, он
   спрашивает, продолжать ли.
2. Границы берутся из разделов тикета `## Relevant Files (Discovery Context)` и
   `## Contract touchpoints` и сверяются с кодом. Раздел `## Out of scope` в руководство не попадает.
   Файл вне границ навык отмечает как требующий одобрения мейнтейнера.
3. Навык назначает тикет на мейнтейнера и меняет метку на `status::in-progress`.

## Руководство

Руководство строится по шаблону `references/guide-template.md` из пяти разделов:

1. контекст и ограничения;
2. карта файлов;
3. шаги с промптами;
4. проверка;
5. действия после реализации.

Каждый промпт самодостаточен, начинается с теста и ссылается на критерий приёмки и его команду
`Verify`. Проверка берётся из критериев `Action -> Verify` тикета или раздела
`## Acceptance & Verification Criteria` спецификации. Руководство пишется на языке из
`.harness/project.json` и сохраняется в `docs/tasks/`, для дочерней задачи — в каталог эпика.
