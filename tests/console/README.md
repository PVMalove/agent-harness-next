# Тесты консоли

Здесь остаются только unit-тесты: разбор ответов, формирование команд, состояния,
фильтрация, форматирование и работа отдельного модуля с временными файлами.
Внешние runners, Git, tracker и health подставляются явно в проверяемом модуле.

Тесты не запускают Textual-приложение, CLI-процессы, настоящий ledger или сеть.
`conftest.py` запрещает `subprocess.Popen` и `App.run_test`: даже перехваченная
проверяемым кодом попытка нарушить границу приводит к падению теста.

Отрисовку и взаимодействие с терминалом владелец проверяет вручную; unit-тесты их не
подтверждают.

Запуск: `.harness/.venv/bin/python -m pytest -q tests/console`.
