# Приёмочные сценарии для прожарки

Запускайте каждый сценарий в новой сессии с установленным `engineering-suite`.
Используйте отдельный тестовый Git-репозиторий. Для проверки снимайте `git status --short`
и сравнивайте содержимое артефакта и доменных документов до и после каждого ответа.

| Сценарий | Ввод | Ожидаемый результат |
|---|---|---|
| Явный выбор путей | В `/grill-me` предложите рассмотреть `src/orders.py` и `tests/test_orders.py`. На отдельный запрос подтвердите только первый путь. | Запрос не расходует ни одного из четырёх вопросов. В артефакте и итоговом чате есть только `src/orders.py`, даже если агент читал тесты. |
| Досрочная остановка | Оставьте корневой выбор открытым и ответьте «остановимся». | Частичный итог содержит блок «Открытые вопросы и блокеры для спецификации». Зависимый вопрос остался открытым. Спецификация и тикет не создаются. |
| Глубокий разбор | На раунд выбора архитектуры ответьте «подробнее 2», затем «подробнее все». | Агент читает шаблон только после запроса и показывает файлы, контракты, верификацию и риски для запрошенных вариантов. Ни один файл не меняется. Агент возвращается к тому же выбору. Только ответ `2` фиксирует вариант 2. |
| Отложенная ветка | Ответьте «отложим этот вопрос» на развилку с зависимыми вопросами. Затем попросите «углубимся сюда» о другой развилке. | Первая ветка остаётся открытой целиком. Вторая остаётся в фокусе до ответа. |
| Передача списка | После итоговой сверки вручную вызовите `/to-spec`, согласуйте тестовые швы и ветку. Повторите с артефактом, запись которого была недоступна. | Раздел `## Relevant Files (Discovery Context)` повторяет одобренные строки из проверенного файла или из итогового чата при сбое. Отклонённый путь и сведения из устаревшего артефакта не попадают в спецификацию. |
| Согласование глоссария | В `/grill-with-docs` явно согласуйте термин при отсутствующем `CONTEXT.md`. Повторите в новом репозитории с read-only глоссарием и с чужими незакоммиченными правками. | В первом случае создаётся глоссарий с согласованным термином. В остальных случаях файл и индекс сохраняются, а термин остаётся в итоговом чате. ADR появляется после отдельного одобрения подходящего решения. |
